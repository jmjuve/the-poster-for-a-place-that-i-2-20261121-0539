A travel poster for **VELMORA — The Floating Isles**: a chain of
islands that drift above a sea of clouds at golden hour, crowned by one
crystal spire. The place does not exist. The poster wishes it did.

`main.py` (pure Python 3.13 standard library, no network) draws the
poster — indigo-to-amber sunset sky, a low golden sun, three floating
islands with waterfalls pouring into the clouds, and the crystal spire
that is the one landmark you travel to see — and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.png` (1024×1024 PNG, ≤1 MiB), with the
repo's `out/` directory only as a local fallback. Two runs write
byte-identical PNGs.

## Run

```sh
python3 main.py
# writes out/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png when set)
```
